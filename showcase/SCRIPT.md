# Showcase script — Call Analysis (2:25)

Recorded against the in-process mock ARAG (`make showcase`, `ARAG_MOCK=1`) over 24 synthetic
health-insurance calls — no real member, agent, or call data anywhere in this recording. Narration
is written to be read aloud in a natural pace while `showcase/record.spec.ts` performs the actions.

| Time | On-screen action | Narration | Viewer takeaway |
|---|---|---|---|
| 0:00–0:12 | Land on the dashboard (`/`). KPI row and charts render. | "This is Call Analysis, built entirely on Progress Agentic RAG. Every number on this dashboard — total calls, first-call resolution, complaint rate, cross-sell acceptance — is generated by AI agents reading real call transcripts. Nothing here is hand-tagged." | The dashboard is a live aggregate, not a mockup. |
| 0:12–0:25 | Scroll to the charts: Calls by reason, Sentiment mix, Cross-sell funnel. | "These charts come straight from labels an ARAG data-augmentation agent assigned to every call — call reason, sentiment, outcome." | The taxonomy is AI-assigned, not configured by a human. |
| 0:25–0:40 | Click the "Complaint rate" KPI to drill into the filtered calls list. | "Click straight through any metric into the calls behind it — here, every call where the agent flagged a complaint." | Metrics are not dead ends; every number is a live filter. |
| 0:40–0:55 | On `/calls`: click a facet chip (Billing & Payments), then type "premium" into transcript search. | "The calls list is fully faceted, and search here isn't a title match — it's semantic search across full transcripts, powered by ARAG's find endpoint." | Search and filtering both hit real transcript content. |
| 0:55–1:15 | Open a call detail page: media player, transcript with moment chips, AI Analysis panel. | "Inside one call: the original recording, a transcript ARAG produced from it, and moment chips — complaint, cross-sell pitch, escalation — a second agent tagged paragraph by paragraph. The Analysis panel on the right is a generated scorecard and executive summary." | One call, fully instrumented — nothing re-typed by a human. |
| 1:15–1:20 | Click "Summarize this call" in the Ask panel. | "Now the moment this product is built for." | Sets up the wow moment. |
| 1:20–1:45 | Answer streams token by token; inline citation markers `[1]` appear in the prose; a confidence badge and source chips land under the answer. | "The answer streams live, grounded only in this call's own transcript, with inline citations as it writes." | The answer is not canned — it is generated and cited in real time. |
| 1:45–2:00 | Click citation `[1] source`; the transcript paragraph flashes and the player scrubs to that timestamp. | "Click a citation, and the transcript jumps to the exact paragraph it came from, scrubbing the recording to that second. That confidence badge isn't decoration — it's a real score from ARAG's REMi answer-quality model." | Citations are provably traceable, and confidence is a genuine model score, not a guess. |
| 2:00–2:10 | Open "How this works" from the Progress band. | "Every page has a How this works panel — this is the real request path this page takes, not a marketing diagram." | Transparency: the architecture claims are checkable on the spot. |
| 2:10–2:20 | Sign in to `/admin` with the admin token; open Health, then Agents. | "Operators get a real admin panel: a live Knowledge Box connection test, and status for the three data-augmentation agents doing all this labeling and writing." | Production-grade operability, not just a demo UI. |
| 2:20–2:25 | Open `/api/v1/docs` (Redoc). | "It's all one versioned API, `/api/v1`, documented here — and the whole thing you just watched runs with no credentials at all, against a mock Knowledge Box." | The product is API-first and runnable by anyone in minutes. |
